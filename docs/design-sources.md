# Coursekin design research

Reviewed September 15, 2026. The user requested design award references such as Awwwards.

## Scope

Screened 100 rendered preview images from the first 100 entries in the Awwwards Site of the Day gallery, excluding promoted entries. This is a collection of award winners ordered by recency, not an official numeric top 100 ranking. The numbers below are research index positions, not jury ranks. Opened three selected websites live for a closer look. The remaining entries received a gallery preview review, not a complete interaction audit.

## Selected references

| Reference | Observed characteristics | Applied to Coursekin |
| :--- | :--- | :--- |
| [Aspen Search](https://www.awwwards.com/sites/aspen-search) | Oversized sans typography, strong grid, restrained borders, clear mint accent | Confident headline scale, aligned form edges and quiet navigation |
| [Illoca](https://www.awwwards.com/sites/illoca) | Warm paper tones, cobalt contrast, generous type and editorial structure | Warm background and a single cobalt primary action |
| [Aardvark Book Club](https://www.awwwards.com/sites/aardvark-book-club) | Expressive book focused identity, cheerful color, playful controls | Friendly pastel upload areas and clear, tactile interaction feedback |

The palette, layout, wordmark and components are original Coursekin work. No third party logos, images, CSS, proprietary fonts or other website assets are shipped in the app. The selected references all appeared in the first 18 entries of the reviewed gallery.

## Design system

Warm paper background `#f7f6f0`, charcoal text `#202526`, cobalt action `#414ee0`, pale lime textbook panel `#e9edcf`, pale lavender syllabus panel `#e7e4f4`. Arial provides a readily available interface font and Georgia adds an italic accent to the headline. The layout has an open main canvas, a class navigation rail, two distinct document areas and one main action.

The user flow remains: name class, add textbook and syllabus, ask questions. Color indicates the document's role. Focus and drag states make the next action clear. Motion is restricted to short control transitions, and reduced motion preferences are respected.
