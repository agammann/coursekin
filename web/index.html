Where to generate answers

Device models are experimental and can make basic reasoning errors. Hosted answers use your own API billing account. Every answer still needs source review.

Runs on your device

First download needs storage and a compatible WebGPU graphics device. Model files come from public hosts; your prompts stay on this device. Coursekin never switches to paid answers automatically.

Use your own OpenAI account

Your question, up to six selected excerpts and the last four conversation messages pass through Coursekin to OpenAI. Usage is billed to your API account. The key stays in tab memory and clears on reload or switching to device mode; it is excluded from class backups. Requests use store: false; OpenAI's data policies still apply.

Class materials

PDF, DOCX, TXT or Markdown, up to 25 MB per file. Scanned PDFs need OCR first.
